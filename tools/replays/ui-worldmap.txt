# ui.menus = ps2, the world map: the PS2 picture (converter, sgjob.rs) and what
# mod/WorldMapPatches.cs draws over it, through tools/calllist (docs/ui.md, "The world map"). Give
# the converter's ui output (efl/x) as the mod: then the picture is the PS2's in every shot (a file
# swap); run without the mod for the HD picture. From save slot 1 (salvage ship deck): open the
# main menu (Sg_MenuSetReserve; the menu open 0x008aa780 registers menu 0x17 = TkMenuCtrlWorldMap
# with the others but activates only the main menu), then activate the world map as the game's own
# TkMenuCtrlItem does in its state 7 (TkMenuMainActiveMenu(0x17, 0)), wait for the fade-in
# (+0x64 = 0x80), shoot (the PC's HD location bar); point the window's draw at the PS2 draw
# (@ps2screen worldmap), shoot; the 4:3 write and a shot.
# The save's map marker may be 0 (then no marker scene, as on both).
load direct 1 cdsp0000 lockstep
lockstep on
pin
wait 120
call 0x00821750 0x17
wait 60
call 0x008aa100 0x17 0
wait 120
read 0x01871698 4
shot $OUT\wm-1-hd.bmp
@base
# the PS2 text line (mod Ps2Menu.install: no glyph y offset, 20-line line feeds)
@alloc YF 4096
@protect YF 0x008e9000 4096
@ps2font YF
@alloc N 4096
write {N} 2f4646585f446174612f47616d65446174612f505333446174612f6d656e755f75732f44334431312f70733277696e2e6464732e706879726500
call 0x006651d0 {=N}
@alloc F 4096
write {F} 2f4646585f446174612f47616d65446174612f505333446174612f6d656e755f75732f44334431312f707332666e742e6464732e706879726500
call 0x006651d0 {=F}
wait 20
@alloc O 4096
@alloc T1 65536
@thunk T1
@ps2screen worldmap O N F T1
wait 2
shot $OUT\wm-2-ps2.bmp
write 0x00c34154 abaaaa3f
wait 2
shot $OUT\wm-3-ps2-43.bmp
