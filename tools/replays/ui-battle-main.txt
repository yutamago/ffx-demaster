# ui.menus = ps2, battle: the main command window as the mod's hook draws it.
# The cursor is the PS2 one (the mod's TOMakePktShapeCursor hook: meswin shape 45 from the
# converter's ps2win, which the run loads; give the converter's ui output as a mod).
# Run with tools/calllist, not shotrun: the @ lines are its commands (docs/ui.md, "The battle command windows").
# The window's draw callback (+0x90) is pointed at a call-list thunk holding the calls the
# hook makes (PS2 rectangle, dum91 -> dum92 gradient box, the scroll part, the scissor, the
# names, the cursor), so the game itself makes them during its update.

@thunk T
