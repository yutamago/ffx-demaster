# state battle-kami is a random encounter outside the Thunder Plains agency
# from save 5, battle field 34 (kami00), group 0, formation 1 (read in the
# PS2's memory: PS2 0x00318c76 u16 field, +2 group, +3 formation, +4 the
# field's name, = PC 0x0112c256). The same battle here, then the main
# command window drawn the PS2 way through calllist as in
